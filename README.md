# Sistema de Reservas de Hotel

Trabalho avaliativo desenvolvido em Python aplicando os paradigmas de programação procedural e orientada a objetos.

## Estrutura do Projeto
- `main.py`: Menu principal e fluxo do sistema
- `models.py`: Classes (`Cliente`, `Quarto`, `QuartoSolteiro`, `QuartoCasal`, `QuartoSuite`, `Reserva`)
- `utils.py`: Funções auxiliares para validação de data e limpeza de terminal

## Como executar
No terminal, dentro da pasta do projeto, execute:
```bash
python main.py
```
